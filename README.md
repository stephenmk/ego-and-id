# The Ego and the Id

This repo contains my working directory for my ebook production of Joan Riviere's 1927 translation of Freud's *The Ego and the Id*.

The finished product is published by Project Gutenberg:

https://www.gutenberg.org/ebooks/79682

You can also view a different HTML version here on GitHub which contains the original page numbers in the margin. The page numbers are linked to images of the original scanned pages.

https://stephenmk.github.io/ego-and-id/book.html
